## Introduction

Ugarit Tinker is a powerful REPL for the Ugarit framework.

## Official Documentation

Documentation for Tinker can be found on the [Ugarit website](https://ugarit.com/docs/scribe#tinker).

## Contributing

Thank you for considering contributing to Tinker! The contribution guide can be found in the [Ugarit documentation](https://ugarit.com/docs/contributions).

## Code of Conduct

In order to ensure that the Ugarit community is welcoming to all, please review and abide by the [Code of Conduct](https://ugarit.com/docs/contributions#code-of-conduct).

## Security Vulnerabilities

Please review [our security policy](https://github.com/ugarit/tinker/security/policy) on how to report security vulnerabilities.
